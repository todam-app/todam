# Politique de marque Todam

Le code source de Todam est open source. Le nom « Todam », le logo Todam et les
éléments distinctifs de son identité ne sont pas accordés par les licences
Apache-2.0 ou AGPL-3.0.

## Usages permis

Sans autorisation préalable, il est permis :

- de mentionner fidèlement le projet Todam ;
- d'indiquer qu'un logiciel est « fondé sur Todam » ou est un « fork de
  Todam » ;
- d'utiliser le nom pour contribuer au dépôt officiel ou en parler.

Ces usages ne doivent pas laisser croire à une approbation, un partenariat ou
un caractère officiel qui n'existe pas.

## Forks et distributions

Un fork ou une distribution modifiée doit adopter un autre nom, un autre logo
et une identité qui ne prête pas à confusion. Une mention descriptive de
l'origine reste permise.

Cette politique ne limite pas les droits accordés sur le code et ne remplace
pas une future recherche d'antériorité, un dépôt de marque ou une validation
juridique du nom Todam.
