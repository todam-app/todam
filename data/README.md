# Données de catalogue

Le code d'import de Todam est open source, mais les données culturelles ne sont pas
automatiquement couvertes par les licences du logiciel.

- `fixtures/` contient uniquement des données synthétiques redistribuables, utilisées
  par les tests et la CI.
- `private/` est ignoré par Git. Il accueille les catalogues réels tant que leurs droits
  de redistribution n'ont pas été confirmés.

Un catalogue réel doit conserver ses URL sources, sa date de consultation et son statut
de droits. Les descriptions, photographies et affiches ne doivent jamais être copiées
sans autorisation.
