# Gouvernance de Todam

Todam adopte une gouvernance initiale dirigée par son
fondateur-mainteneur. Cette structure simple doit permettre d'avancer tout en
gardant les décisions importantes visibles et contestables.

## Rôles

- **Fondateur-mainteneur** : fixe la direction produit initiale, tranche les
  décisions bloquées, gère les versions et la sécurité.
- **Mainteneurs** : examinent les contributions, protègent la cohérence
  technique et font appliquer les règles du projet.
- **Contributeurs** : proposent des Issues, Discussions, données,
  documentation ou code sous le DCO.

Le fondateur-mainteneur initial est
[@alexisolivari](https://github.com/alexisolivari).

## Décisions

- Les corrections courantes sont décidées dans les pull requests.
- Les changements de produit, de modèle de données, d'API publique, de licence
  ou de gouvernance commencent dans une Issue ou une Discussion.
- La décision finale et ses raisons sont consignées publiquement.
- Les urgences de sécurité peuvent être traitées en privé, puis documentées
  après correction sans divulguer d'informations exploitables.

## Devenir mainteneur

Un contributeur peut devenir mainteneur après des contributions régulières,
fiables et respectueuses des frontières de licence. La nomination est annoncée
publiquement par le fondateur-mainteneur.

## Évolution

La gouvernance sera réévaluée lorsque le nombre de mainteneurs ou l'activité du
projet le justifieront. Une modification de ce document suit le même processus
public que les autres décisions structurantes.
