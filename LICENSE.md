# Licences de Todam

Ce dépôt est un monorepo à licences multiples. La licence applicable dépend du
chemin du fichier.

## Apache License 2.0

Les chemins suivants sont placés sous Apache-2.0 :

- `apps/todam/**`
- `packages/contracts/**`
- `packages/design-system/**`
- `docs/**`
- les fichiers de documentation, de configuration, d'automatisation et les
  outils communs à la racine, sauf mention contraire explicite

Le texte complet se trouve dans
[`LICENSES/Apache-2.0.txt`](LICENSES/Apache-2.0.txt).

## GNU Affero General Public License v3.0

Les chemins suivants sont placés sous AGPL-3.0 :

- `apps/api/**`
- `apps/jobs/**`
- `packages/domain/**`
- `packages/database/**`

Le texte complet se trouve dans
[`LICENSES/AGPL-3.0.txt`](LICENSES/AGPL-3.0.txt).

Chaque futur `package.json` doit déclarer l'identifiant SPDX correspondant au
chemin du package. Les manifestes initiaux inclus dans ce dépôt le font déjà.

## Contributions

Une contribution acceptée est publiée sous la même licence que le chemin dans
lequel elle est intégrée. Le projet utilise le DCO et aucun CLA. Aucun droit
supplémentaire n'est demandé aux contributeurs pour republier leur contribution
sous une licence fermée.

## Éléments exclus

Les licences du code n'accordent aucun droit sur :

- le nom, le logo ou l'identité visuelle Todam, régis par
  [`TRADEMARKS.md`](TRADEMARKS.md) ;
- les données personnelles ;
- les affiches, photographies ou autres contenus de tiers ;
- les jeux de données importés, sauf licence explicitement indiquée avec le jeu
  concerné.

Ce document décrit l'intention de licence du projet et ne constitue pas un
conseil juridique.
