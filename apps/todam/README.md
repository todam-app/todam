# Application Todam

Application universelle Expo de Todam. Elle fournit les routes Accueil, Recherche,
Spectacle, Connexion, Inscription et Profil sur Web, iOS et Android.

Copier les variables de `../../.env.example`, démarrer PostgreSQL et l'API, puis lancer
:

```bash
pnpm --filter @todam/todam dev
```

Emplacement réservé à la future application Expo universelle pour le Web, iOS et
Android.
