# Registre et procédure d'incident

Le registre réel est confidentiel et ne doit pas être placé dans Git. Pour chaque
incident, enregistrer dans un outil privé : identifiant, découverte, période, systèmes,
catégories de données, personnes concernées, volume, gravité, mesures immédiates, cause,
remédiation et clôture.

## Procédure

1. contenir l'incident sans détruire les preuves ;
2. révoquer les secrets, sessions ou accès concernés ;
3. déterminer les données, personnes et conséquences possibles ;
4. documenter l'analyse du risque ;
5. notifier la CNIL dans le délai applicable lorsque requis ;
6. informer les personnes lorsque le risque élevé l'exige ;
7. restaurer, surveiller et consigner les mesures correctives ;
8. réaliser un retour d'expérience sans données personnelles dans Git.
